# Rocket — передача файлов между Windows и Android

**Выбрал файлы → провёл слайдер «Поехали!» вправо → ракета полетела.** На экране только ракета, одна кнопка и шестерёнка настроек. Когда файлы долетели, ракета улетает за край экрана, а из дыма появляется статистика: сколько файлов, объём, время и средняя скорость. На ПК и на телефоне всё выглядит и работает одинаково.

## Как пользоваться

1. Запусти `rocket.exe` на ПК (двойной клик) и установи `android/app/build/outputs/apk/debug/app-debug.apk` на телефон. Пока нужен обмен, держи Rocket открытым: на ПК окно, на телефоне экран.
2. **Телефон → ПК.** На телефоне нажми «Выбрать файлы» (или «Поделиться» из Галереи) и проведи слайдер. ПК телефон находит сам. Файлы сохраняются в Windows Downloads или в папку из настроек ПК.
3. **ПК → телефон.** На ПК нажми «Выбрать файлы» или просто перетащи файлы в окно. Единственный открытый телефон выбирается сам, если телефонов несколько, выбери нужный в строке «На …». Проведи слайдер: телефон сам скачает файлы.

**Если устройств несколько:** адресат выбирается на отправителе одним касанием по строке «На …» и запоминается. Если ПК сменил IP, телефон находит его заново по ID без твоего участия.

**Ограничения:** при передаче ПК → телефон Rocket должен быть открыт на телефоне. Если уйти из приложения или погасить экран, передача остановится. Если подтверждение потеряно, повторная попытка может создать копию с `(1)`. Файлы с неизвестным размером телефон пока не отправляет.

## Настройки (шестерёнка)

Всё, что не нужно каждый день, спрятано сюда.

- **ПК:** папка приёма (изменить, открыть), адреса ПК в сети, проверка связи (сервер, поиск устройств, брандмауэр), список недавних телефонов. Кнопка «Исправить» открывает правила брандмауэра через запрос UAC.
- **Телефон:** какой ПК выбран (найти, ввести IPv4), папка приёма (системная `Download` или любая другая), проверка связи, имя и версия.
- В консоли: `rocket.exe help`, `rocket.exe settings show`, `rocket.exe daemon` (без окна), `rocket.exe firewall install` (из терминала администратора).
- **Без TLS, паролей и аутентификации — по требованию владельца.** Используй только доверенную локальную сеть. CRC32C ловит случайную порчу, но не защита.

## Сборка

```powershell
go test -race ./...; go vet ./...
go build -trimpath -ldflags='-s -w' -o rocket.exe ./cmd/rocket
cd android; .\gradlew.bat :app:assembleDebug --offline --no-daemon
```

Иконка пользователя лежит в `assets/icon-source.png`. Из неё `go run ./tools/genassets` вырезает ракету и создаёт все растры для Android и Windows (подробности и вшивание иконки в EXE — в [docs/BUILD_TEST.md](docs/BUILD_TEST.md)). Дальше читай [docs/HANDOFF.md](docs/HANDOFF.md) и [docs/OPEN_ISSUES.md](docs/OPEN_ISSUES.md).

Интерфейс следует языку системы: RU или EN. Отрисовка идёт в ритме дисплея (на Android `postInvalidateOnAnimation` и запрос высокой частоты, на Windows Direct2D со vsync). Покой экрана не перерисовывается. Реальные 120 показанных кадров/с на телефонах пока не измерены.
